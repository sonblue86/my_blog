## Mô hình ngôn ngữ lớn là gì?

Mô hình ngôn ngữ lớn (Large Language Model — LLM) là một mạng nơ-ron được huấn luyện trên lượng văn bản khổng lồ để dự đoán từ tiếp theo. Nghe đơn giản, nhưng khi quy mô đủ lớn, khả năng dự đoán ấy biến thành năng lực viết, tóm tắt, dịch và lập luận ở mức đáng kinh ngạc[^1].

> Mọi công nghệ đủ tiên tiến đều không thể phân biệt được với phép thuật.
> — Arthur C. Clarke

### Token là gì?

Token là đơn vị nhỏ nhất mà mô hình xử lý. Một từ tiếng Việt có thể bị tách thành nhiều token, vì vậy cùng một nội dung, tiếng Việt thường tốn nhiều token hơn tiếng Anh.

- Token có thể là một từ, một phần của từ hoặc một dấu câu.
- Chi phí sử dụng API thường tính theo số token.
- Cửa sổ ngữ cảnh (context window) cũng đo bằng token.

### Nhiệt độ (temperature)

1. Nhiệt độ thấp: câu trả lời ổn định, ít sáng tạo.
2. Nhiệt độ cao: câu trả lời đa dạng, đôi khi bay bổng.
3. Chọn mức phù hợp với tác vụ.

## Ví dụ mã nguồn

Đoạn mã dưới đây gọi một API giả lập:

```ts title="src/ask.ts" {3-4}
type Message = { role: 'user' | 'assistant'; content: string };

export async function ask(messages: Message[]): Promise<string> {
  const res = await fetch('/api/chat', { method: 'POST', body: JSON.stringify({ messages }) });
  if (!res.ok) throw new Error(`Lỗi ${res.status}`);
  return (await res.json()).text;
}
```

Và một lệnh terminal:

```bash
npm create astro@latest nhip-so -- --template minimal
```

## Đoạn văn dài để thử nghe bài

Buổi sáng ở Hà Nội bắt đầu bằng tiếng còi xe và mùi cà phê. Người ta vội vàng mở điện thoại, lướt qua tin tức, trả lời tin nhắn công việc trước cả khi kịp đánh răng. Công nghệ giúp ta kết nối, nhưng cũng lấy đi những khoảng lặng.

Có lẽ điều quan trọng không phải là dùng ít hay nhiều công nghệ, mà là dùng nó một cách có chủ đích. Một ứng dụng tốt là ứng dụng giúp bạn hoàn thành việc cần làm rồi để bạn yên. Một bài viết tốt là bài viết giúp bạn hiểu thêm điều gì đó rồi để bạn suy ngẫm.
